# FlowBoard Frontend (Vite + React)

This folder contains a minimal Vite + React scaffold for the FlowBoard frontend.

Prerequisites:
- Node.js (LTS) installed locally
- npm or pnpm available on your machine

Quick start:

```bash
cd FlowBoard-ISD-Project/frontend
npm install
npm run dev
```

The dev server will show a local URL (e.g. http://localhost:5173).

Note: I scaffolded the files; you need to run the above commands locally because `npm` is not available in this environment.
